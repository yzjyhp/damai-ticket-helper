  大麦抢票助手 - 使用说明
═══════════════════════════════════════════

【这是什么】
一个可视化抢票工具：自动在手机上完成
选场次 → 选票价 → 设置数量 → 选观演人 → 提交订单 → 跳转支付页。
所有环境（Node + Appium + adb）都打包在 exe 内，无需安装任何东西。

【第一次使用（或换电脑/换手机）】
1. 双击「抢票助手.exe」
   - 首次运行：自动解压运行环境（约30秒，有进度窗口提示，不是卡死）
   - 之后运行：直接秒开
2. 手机用USB线连电脑
3. 手机上开启「USB调试」：
   设置 → 关于手机 → 连点「版本号」7次 → 返回设置
   → 开发者选项 → 打开「USB调试」
   → 连接电脑后手机弹出授权窗口，勾选「始终允许」并点「允许」
4. 点红色「一键检测环境」
   它会自动：检查环境 → 识别手机（自动适配）→ 检查大麦APP → 启动服务器
5. 若提示「未检测到手机」：换根数据线/换USB口，或安装手机品牌的USB驱动
6. 若提示「大麦APP未安装」：在手机上安装大麦APP并登录

【日常使用】
1. 手机连电脑，开启USB调试，保持亮屏
2. 打开「抢票助手.exe」，点「一键检测环境」确认：服务器✅ 手机✅ 大麦✅
3. 填好「抢票配置」（演出/城市/场次位置/票价位置/观演人），点「保存」
4. 手机进入大麦，停在目标演出的页面（详情页或选票页均可）
5. 选模式：
   - 绿色按钮「开售秒抢」：唯一抢票入口。有票立刻抢；没票/未开售自动刷新等待，
     开售或有票的瞬间自动抢（推荐，一直用这个就行）
   - 「循环抢票」：已开售且票很抢手，反复抢到成功为止
6. 跳转支付宝后，手动完成付款锁票

【多配置管理】
可以保存多套配置，快速切换不同演出：

配置栏: [配置 ▼] [新建] [保存] [另存为] [删除]

- 下拉框：选择已有配置，自动加载到界面
- 新建：清空所有输入框，开始填写新配置
- 保存：覆盖保存到当前配置（新建状态下会提示输入名称）
- 另存为：输入新名称保存为新配置，不影响原配置
- 删除：删除当前配置（默认配置不可删）

使用场景：
- 同时关注多场演出 → 每场演出存一个配置，快速切换
- 同一场演出不同价位 → 存多个票价配置，有票时快速切换抢不同价位

【配置说明】
演出关键词：在大麦里搜索的名字
城市：演出城市（脚本不会改城市，请自己在手机上选好）
日期：如 9.25
场次位置：9.25 是第几个场次卡片（第1个填1，第2个填2…）
票价：如 380
票价位置：380 是第几个票价卡片（第1个填1，第2个填2…）
观演人：几个人买几张票（最多6张），姓名与大麦账号一致，逗号分隔
自动提交订单：勾选=提交订单跳支付页；不勾=演练模式（不真下单）
提交重试(0=无限)：提交订单失败时的重试次数。0=无限重试直到成功

【间隔设置（毫秒）】
开售检测轮询间隔：秒抢模式检测开售的频率（默认200毫秒）
页面刷新间隔：秒抢模式强制刷新页面的频率（默认2000毫秒）
步骤间间隔：选场次/票价/观演人之间的等待（默认500毫秒）
连续点击间隔：点数量加号等（默认150毫秒）
滚动后等待 / 页面加载等待：切页后的等待
提示：抢票时机紧张调小，手机卡顿调大。改完点「保存间隔设置」。

【注意事项】
- 首次启动需要解压环境（约30秒），之后秒开，不是卡死
- 手机保持亮屏、别锁屏、USB 别拔
- 抢到订单后立刻在支付宝付款；不付款约15分钟自动取消
- 换场次务必改对「场次位置」和「票价位置」
- 缺货登记 ≠ 买到票！缺货/无票时用绿色「开售秒抢」等补货
- 关闭程序时会自动清理 Appium/Node/adb 等子进程，无需手动结束
- 本工具仅供学习研究，请遵守大麦网使用条款
